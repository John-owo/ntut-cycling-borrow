社車借還系統隱私權政策

適用網站：https://john-owo.github.io/ntut-cycling-borrow/ ・ 最後更新：2026-10-13

我們收集哪些資料

  • 預約時填寫的學號與姓名，以及預約的車輛、配件與時段。
  • 取車與還車時拍攝的車況照片、車況檢查結果與備註、手寫簽名圖像、簽署姓名與當時的借車規範版本。
  • 系統操作紀錄與伺服器時間。為防止濫用，會記錄連線來源 IP 的雜湊值（不保存原始 IP），約一天後清除。
  • 你的手機瀏覽器會保存一組隨機取還車碼，用來讀取自己的預約；伺服器只保存它的雜湊值。

資料用途

只用於社車預約、幹部審核、取還車紀錄、車況與損壞責任釐清，以及社團內部的車輛管理。不做行銷、不出售、不提供給社團以外的人。

資料存放位置與誰能看到

  • 預約、簽署與操作紀錄存放於 Supabase 資料庫；網站由 GitHub Pages 提供。
  • 車況原始照片存放於社團管理的 Google 雲端硬碟資料夾（較早的照片存於上述資料庫）。
  • 只有登入並通過驗證的社團幹部能查看全部紀錄；社員只能透過自己手機上的取還車碼查看自己的預約與照片。公開的預約日曆不顯示姓名、學號或照片。

Google 使用者資料

本系統只以社團自己的 Google 帳號，透過 Google Drive API 的 drive.file 權限，把借還車照片存入社團建立的資料夾，並只存取本系統建立的檔案。系統不會要求社員登入 Google，也不會讀取任何使用者的 Google 帳號、雲端硬碟或其他 Google 資料。取得的 Google 資料不會用於廣告、不會轉讓，也不會用於訓練人工智慧模型。本系統對 Google API 資料的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

保存期限

照片、簽署與借還紀錄是借車責任的證據，系統不會自動刪除。社團尚未訂定固定的保存期限，訂定後會更新本頁。

你的權利與聯絡方式

如需查詢、更正，或對資料處理有疑問，請私訊社團 Instagram ↗。仍在借用中或尚待處理的紀錄，可能需保留至借還責任釐清為止。

Privacy policy (English summary)

This site handles bicycle bookings for the NTUT Cycling Club. We collect the student ID and name entered when booking, booking details, pickup and return photos, inspection notes, a handwritten signature, and operation logs (with a hashed, short-lived network source for abuse control). Data is used only for bookings, officer approval, loan records and bike management; it is never sold or used for marketing. Records are stored in Supabase; original photos are stored in a Google Drive folder managed by the club. Only verified club officers can see all records; members see only their own booking through the code saved on their phone. The service uses the club's own Google account with the drive.file scope solely to store and read the photos it creates; it never asks members to sign in with Google and never accesses their Google data. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. No fixed retention period has been set yet; records are not deleted automatically. Contact: the club's Instagram, @ntut_cyclingclub.
